# Maintenance changes

Changes made by the Hyperion360 maintenance fork on top of the upstream import (see docs/PROVENANCE.md). Each entry lists the confirmed defect, its exact reproduction, and the repair. This file starts as a blocker inventory and grows as repairs land.

## Eval and message_text inventory (Task 5)

All 67 reachable `eval()` call sites outside the installer follow one pattern: `eval($code['code_text'])` over rows of `fanfiction_codeblocks` selected by a fixed hook type (`sitestats`, `storyblock`, `storyindex`, `storyend`, `printstory`, `storyblock-listing`, `login`, `search`, `categories`, `recent`, `authorpage`, and module hooks). Writers of that table are the installer's defaults, module installation through the admin area (code text comes from module files on disk, not from request input), and the admin. No author, member, or visitor path writes `fanfiction_codeblocks`. The hooks therefore classify as admin-controlled code, equivalent to "install a module", and were not rewritten; a future hardening pass could require an explicit allowlist setting.

Writers of `fanfiction_messages.message_text`: install/install.php step 7 (behind the owner secret and CSRF gate), admin/custpages.php and admin/messages.php (now token-gated, items 22 and 23), and install/upgrade11.php / install/upgrade20.php (disabled entirely, item 24). No other code path writes message text; viewpage.php renders it without executing (item 22).

Security defects (viewstory.php access condition, viewpage.php eval, CSRF in admin/custpages.php and admin/messages.php) are tracked in the Task 5 section below once confirmed with tests.

## Repairs

- 2026-10-14 `fix: remove PHP 8 runtime blockers`: items 1 to 6 and 8 above. Verified with `sh tests/compat/lint.sh` (all files parse) and `php -d zend.assertions=1 -d assert.exception=1 tests/compat/runtime.php` on PHP 8.3.35 and 8.4.8. Guest/author page rendering is exercised by the Task 4 HTTP harness.
- 2026-10-14 `fix: support current MySQL and MariaDB defaults`: item 7 above plus two adjacent guest-data exposures found while testing the wrapper:
  - dbquery now catches mysqli_sql_exception (the PHP 8.1+ default behavior) and routes failures through accessDenied. Previously the exception bypassed the old `or accessDenied(...)` guard and a failing query could surface the SQL text in a PHP fatal page.
  - `?debug` (query dumps in HTML comments, full error reporting) is now admin only. header.php applied it for any visitor who typed the parameter.
  - Verified with `EF_DB_NAME=efiction_test_ci php tests/compat/database.php` on MySQL 8.0.46 and MariaDB 10.6.23, PHP 8.3.35 and 8.4.8: apostrophe/Unicode round trip, null and empty-string inserts, no SQL leakage on failing queries, no credential echo on connect failure.
- 2026-10-14 `fix: complete a full install on PHP 8.3 and MySQL 8 defaults`: items 10 to 15 above, found by driving the real installer over HTTP (the browser-install harness). A fresh install now renders 27 tables, creates the admin, and completes with zero PHP warnings or deprecations on PHP 8.3.35 and 8.4.8 against MySQL 8.0.46 and MariaDB 10.6.23.
- 2026-10-14 `fix: make shared-host install and upgrade safe on PHP 8.3`: the installer owner-secret and CSRF gate (POST-only mutators, atomic config write with a state marker, one-time recovery of marker-verified content-free partial installs), update.php reduced to a no-write status page for 3.5.5 archives, README.txt permission advice, and items 16 to 20 above. Verified with tests/compat/http.sh fresh and upgrade in all four local cells (PHP 8.3.35 and 8.4.8 x MySQL 8.0.46 and MariaDB 10.6.23): fresh installs create all 27 tables plus the admin with no PHP warnings; the preserved 3.5.5 fixture (tests/fixtures/, generated by the gated installer with engine-neutral utf8mb4_general_ci so the dump loads on both engines) keeps schema, config, story files, and preserved rows byte-identical across file replacement; the only remaining fresh-mode failure is the unpublished-story access condition, fixed under Task 5.

- 2026-10-14 `fix: close the unpublished story and stored code defects`: items 21 to 24 above, each reproduced first by tests/compat/security.php against the preserved 3.5.5 fixture (15 failing checks before the repairs, 24 passing after). Eval and message_text writer inventory appended above.
